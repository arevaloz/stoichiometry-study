# Stoichiometry Study

Interactive flashcards built from your balancing equations & stoichiometry study guide PDF.

## How to open

1. Open File Explorer to `C:\Users\sergi\Projects\stoichiometry-study`
2. Double-click `index.html` (opens in your browser)

Or in Cursor: right-click `index.html` → Open with Live Preview / reveal in Explorer.

## What’s inside

- **Core ideas** — balancing, moles, mole map, limiting reactant, percent yield
- **Balance these** — practice equations from the guide
- **Stoichiometry practice** — mole and gram problems
- **Common mistakes** — traps to avoid

Click a card to flip. Use **Again** / **Got it** to track the session. **Shuffle deck** randomizes order.

## Files

- `index.html` — page structure
- `styles.css` — look and layout
- `cards.js` — the sample questions (edit this to add more)
- `app.js` — flip / navigate / score behavior
